# AntiYaware
AntiYaware script (Python)

Трекер Yaware часто настроен на мониторинг продуктивности. Скрипт будет имитировать работу пользователя, причем более естественно, чем обычный кликер:
шевелить курсором, переключается между окнами запущенных программ (кроме окна самого скрипта) и скролить их содержимое. 

Порядок установки (все действия нужно выполнить под учетной записью, где работает Yaware):
  1. Собственно Python (скачиваем и устанавливаем)
  2. Установливаем библиотеки Python командой в терминале:
  2.1. python -m pip install pyautogui 
  2.2. python -m pip install pygetwindow

Сам скрипт work_process запускаем также из терминала, после чего его можно свернуть.  
Для завершения работы скрипта, переместите курсор в любой угол экрана.
